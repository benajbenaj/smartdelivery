# Commit 01 — Initialize Repository

## Monorepo Structure

This project keeps deployable parts in separate top-level areas:

- `apps/api-go` contains the merchant-facing Go backend.
- `extensions/delivery-customization-rust` contains the Shopify checkout function.
- `docker` contains local development services.
- `docs` contains architecture and learning notes.

This keeps each runtime isolated while still allowing shared planning, local tooling, and documentation in one repository.

## Why The Shopify Function Is Separate

The backend can use the database, Shopify Admin APIs, migrations, background jobs, and normal web service patterns.

The Shopify Function runs inside checkout. It must be fast, deterministic, and unable to depend on runtime network calls. Because of that, it should receive a compact configuration generated by the backend instead of querying the backend during checkout.
